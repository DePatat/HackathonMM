### Opening Instructions

The website consists of multiple pages, which can be accessed by clicking on their respective names in the navigation bar located in the top-right section of the header.

The website contains the following pages:

- **Overview:** Briefly describes Augmented Reality (AR) and explains its differences from Virtual Reality (VR). This is also the landing page of the website.
- **Devices:** Displays the devices that are compatible with the proposed AR glasses.
- **Features:** Describes the key features of our idea and presents a typical user journey through step-by-step instructions.
